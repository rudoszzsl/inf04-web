# Podstawowe komendy Gita

**git init**  
Tworzy nowe repozytorium w folderze. Git zaczyna wtedy pilnować plików.

**git status**  
Pokazuje, co się zmieniło i co czeka na zapisanie.

**git add**  
Dodaje plik do kolejki, żeby Git mógł go zapisać.  
`git add .` dodaje wszystkie zmienione pliki.

**git commit -m "opis"**  
Zapisuje zmiany z kolejki. W cudzysłowie piszemy, co zrobiliśmy.

**git log**  
Pokazuje historię zapisów (commitów).

**git branch**  
Pokazuje listę gałęzi. Gałąź to osobna wersja projektu, na której można pracować niezależnie.

**git push**  
Wysyła nasze zapisy z komputera na GitHuba.

**git pull**  
Pobiera z GitHuba najnowsze zmiany na nasz komputer.
